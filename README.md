# 教室鼠鼠大逃亡

## 发布到 GitHub Pages
1. 打开你的仓库：https://github.com/whp2011/mouse-game
2. 点 **Add file → Upload files**。
3. 将 `index.html` 和 `classroom-bg.jpg` 两个文件一起拖进去。
4. 点 **Commit changes**。
5. 打开仓库 **Settings → Pages**。
6. 在 **Build and deployment** 里选择 **Deploy from a branch**。
7. Branch 选择 `main`，目录选择 `/ (root)`，点 **Save**。

发布后网址通常是：https://whp2011.github.io/mouse-game/

## 操作
- 电脑：方向键或 WASD
- 手机：按住屏幕上的方向按钮
